# slides

Talk decks, one folder per talk, built with [Slidev](https://sli.dev).

| Deck | Talk |
|---|---|
| [`ios-swift/`](ios-swift/slides.md) | iOS Swift: the language behind MotivationFit |

```bash
pnpm install
pnpm ios-swift        # dev server + presenter mode (press P)
pnpm ios-swift:pdf    # export to dist/ios-swift.pdf (needs playwright-chromium)
```

Code on the slides is quoted from the MotivationFit iOS app (`ios/Packages/MotivationFitKit`), trimmed for space.
